# Q-Blueprint Submission Instructions

## 1. Fork the Repository
Fork the official Q-Blueprint repository to your GitHub account.

## 2. Create Your Team Folder
Inside the `submissions/` folder, create:

`TEAM_<TeamID>_<TeamName>/`

Example:

`TEAM_07_QubitSquad/`

## 3. Add Your Submission
Your team folder should contain:

- `notebooks/` — Jupyter notebooks
- `report/` — Final report PDF
- `slides/` — Presentation slides
- `requirements.txt` — Python dependencies
- `README.md` — Short description and instructions to reproduce your work

## 4. Commit and Push
Commit your changes to your fork and push them to GitHub.

## 5. Create a Pull Request
Open a Pull Request from your fork to the official Q-Blueprint repository.

Use this title:

`[SUBMISSION] TEAM_<TeamID>_<TeamName>`

Example:

`[SUBMISSION] TEAM_07_QubitSquad`

## Important
- Only modify your own team folder.
- Do not upload passwords, API keys, or other secrets.
- Keep your code reproducible.
- Cite external libraries, papers, code, and AI assistance where applicable.
