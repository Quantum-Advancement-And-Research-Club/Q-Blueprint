## Note on the D2–D6 reconstruction

During final packaging, the original D2–D6 source modules/notebooks could not be located in the available project archives. I therefore prepared a **faithful reconstruction** of the D2–D6 workflow using the report, surviving D1 source code, and accompanying tables/figures as the reference. I apologise for the inconvenience caused by the missing original files and dependencies, and appreciate your understanding while I worked to recover or reconstruct the material.

The reconstructed notebook follows the report's structure: D2 calibration primitives, D3 adaptive Bayesian Ramsey design, D4 device/agent/policy workflow, D5 policy trade-off analysis, and D6 four-qubit ring QAOA and drift ablation. It explicitly labels report-transcribed values as **report-derived** and marks newly computed results as **reconstructed**. It must not be represented as the recovered original implementation or as a rerun of the original 484-day sweep.

## Reproducibility status

The supplied D1 foundation contains `config.py`, `drift.py`, `transmon.py`, and `propagator.py`; the D1 test file covers operators, Hamiltonian properties, pulse area, unitarity, convergence, drift statistics, and seeded reproducibility. The original package map also lists D2–D6 modules (`calib/`, `plant.py`, `agent.py`, `policies.py`, `closed_loop.py`, `qaoa.py`, `run_sweep.py`, and analysis scripts), but these were not present in the recovered archives. Accordingly, this repository separates:

1. **supplied and executable D1 code**;
2. **reconstructed D2–D6 methods**;
3. **report-derived benchmark numbers and figures**.

The report's reported study uses the official seed 2026 plus seeds 1–21 and 22 policy configurations (484 simulated days). Those original results are not claimed to have been independently regenerated by this reconstruction.

## Environment and run instructions

Tested notebook environment: Python 3.13.5 with the exact package versions in `requirements.txt`. From the repository root:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
jupyter lab
```

Run the editable D1 notebook and the D2–D6 reconstruction notebook from top to bottom. The full reconstructed sweep is not enabled by default; begin with the smoke-test examples and enable longer runs deliberately.

Core D1 tests:

```bash
PYTHONPATH=src pytest -q tests/test_phase2_3.py
```
